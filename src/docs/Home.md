# CircuitPython Online IDE Documentation

**_Visit [https://circuitpy.dev](https://urfdvw.github.io/circuitpython-online-ide-2/) to start using the IDE_**

**CircuitPython Online IDE** is a browser-based IDE (integrated development environment) compatible with Chrome or Chromium-based browsers, including on **Chromebooks**.
Whether you are blinking your first LED or building your next gadget, it gets you coding right away. Perfect for DIY makers and for classrooms where installing software is not an option.

New here? Start with the **Getting Started** guide in the left panel.

This IDE includes abundant features for CircuitPython microcontroller projects:

### Essential coding tools

- Folder View
- Editor
- Serial Console

### Coding assistance

- Library Management
- Debugger
- AI Agent Bridge

### Helpful tools

- Plot
- Data Serial
- Connected Variable Widgets
- Camera
- Backup

Check the left panel for detailed help on each feature.
